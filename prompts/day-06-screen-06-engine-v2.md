## المهمة

1. **محرك التكيّف** `src/lib/engine/adjuster.ts` — دالة نقية مدخلاتها (الليالي المسجلة + خطة الأمس + قواعد العمر + سجل الرفض) ومخرجاتها مصفوفة تعديلات:

```ts
interface Adjustment {
  id: string;
  element: 'bedtime' | 'nap' | 'feed' | 'routine'; // أي عنصر من الخطة
  from: string; to: string;           // HH:mm — الفرق ضمن ±5..±15 دقيقة حصراً
  reason: string;                      // جملة أم واحدة: [ماذا] — [الملاحظة] — [المرجو]
  status: 'applied' | 'rejected' | 'pending';
}
```

   القواعد الإلزامية: التدرج ±5–15 دقيقة فقط · لا قرار من ليلة واحدة (ثلاث ليالٍ بنفس النمط = إشارة) · عند emergency أو رصد انحدار: تثبيت كامل + إنزال توقعات · الرفض يمنع تكرار الاقتراح 3 أيام · لا تجاوز لحدود النافذة العمرية.

2. **كشف الاتجاه** `src/lib/engine/trends.ts`: دالة ترصد أنماط ثلاث ليالٍ (تحسن متصل، تدهور، نمط متقلب) وتعيد إشارة مبكرة + مرشح درس من المكتبة (إن كانت بنيت) أو نصاً استباقياً.

3. **الشاشة** `src/components/screens/screen-06.tsx`: رأس + رقيقة ذهبية «تحدّثت الآن» + بطاقة لكل تعديل (من→إلى بأرقام ltr + السبب) + بطاقة «وبقيت الركائز كما هي» + بطاقة ذهبية للإنذار المبكر إن رصده trends + زر «شاهدت خطة اليوم — على الروتين مساءً» + **زر «غير موافق» على كل تعديل** يسجل الرفض ويستعيد القيمة السابقة + مدخل لسجل التعديلات السابقة (تصفح للخلف).

4. **قالب الطوارئ**: إذا كان سجل اليوم emergency=true تُعرض الشاشة بنسخة أهدأ: بطاقة تثبيت واحدة («ثبّتنا توقيتات اليوم كما هي — الأمان أولاً»)، بلا تعديلات، مع رابط «دليل النجاة — يكتمل قريباً» (الشاشة 09 بعد يومين).

5. **الحلقة تُغلق**: زر «سجّلي» في الشاشة 05 ينقل الآن إلى الشاشة 06 مباشرة بعد الحفظ.
