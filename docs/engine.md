# docs/engine.md — محرك التكيّف والملف النامي

> المحرك هو حصرية المنتج الأولى: خطة تُعدَّل كل صباح بشرح مفهوم. يُبنى معزولاً عن الواجهة تماماً (`src/lib/engine/`) بحيث تُحسَّن قواعده دون مساس بالشاشات.

## 1. الملف النامي (Growing Profile)

كائن بيانات واحد يبدأ بأربعة حقول (من الشاشة 02) ويكبر مع كل تسجيل صباحي وكل محادثة:

```ts
interface GrowingProfile {
  // من الشاشة 02 — لا يُسأل عنها مرة أخرى أبداً
  birthDate: string;            // ISO — يُحسب منه العمر بالأيام دائماً
  worstProblem: 'frequent-wakes' | 'late-sleep' | 'held-sleep';
  wakePattern: string;          // نمط الاستيقاظ الليلي
  priorityGoal: string;         // هدف الأولوية

  // ينمو مع الاستخدام
  nights: NightRecord[];        // سجل الليالي (من الشاشة 05)
  adjustments: Adjustment[];    // سجل التعديلات والرفوض (من 06)
  chatSummaries: string[];      // تلخيص كل محادثة (من 07)
  routineTemplate: string;      // قالب الروتين المختار (من 04)
  milestones: string[];         // الإنجازات (لـ 08)
}

interface NightRecord {
  date: string;                 // ISO
  sleepTime: string;            // HH:mm — وقت النوم الفعلي
  wakeCount: number;            // عدد الاستيقاظات
  morningMood: 'rested' | 'tired' | 'hard';
  emergency?: boolean;          // هل فُعّل وضع الطوارئ
}
```

التخزين: Zustand persist (localStorage) — يعمل بلا إنترنت. **لا حساب قبل رؤية الخطة (الشاشة 03).**

## 2. القواعد العمرية الموثقة (جدول التوقيتات)

الخطة الأولى (شاشة 03) تُولَّد من جدول نوافذ اليقظة والتوقيتات حسب العمر بالأشهر + إجابات الشاشة 02:

```ts
interface AgeRules {
  monthsFrom: number;
  monthsTo: number;
  wakeWindowMorning: [number, number];   // بالساعات — نطاق
  wakeWindowAfternoon: [number, number];
  bedtimeRange: [string, string];        // HH:mm — نطاق موعد النوم
  nightSleepExpected: [number, number];  // ساعات متوقعة
  maxAwakeBeforeBed: number;             // أقصى يقظة قبل النوم
  regressionWindows: number[];           // أشهر الانحدار الشائعة (4، 6، 8-10، 12، 18...)
}
```

**تنبيه إلزامي**: القيم الرقمية تُعبأ من نطاقات نوافذ اليقظة المنشورة على نطاق واسع في أدبيات استشارات نوم الرضع، وتُعايَر قبل الإطلاق مقابل مصدر موثق واحد على الأقل. اكتب القيم الأولية في `src/lib/engine/age-rules.ts` مع تعليق «قيم أولية — تعاير قبل الإطلاق» وأبلغ المستخدم بأن المعايرة بند في قائمة ما قبل الإطلاق.

## 3. قواعد التكيّف (الشاشة 06)

المدخلات: ليلة أمس + اتجاه آخر ثلاث ليالٍ + العمر بالأيام + سجل الرفض.

```
قاعدة التدرج: التعديل ±5 إلى ±15 دقيقة فقط في المرة الواحدة، ولا يتجاوز حدود
             النافذة العمرية الموثقة لعمر الطفل.
قاعدة الاتجاه: ثلاث ليالٍ بنفس النمط = إشارة تُبنى عليها قرارات اليوم (لا قرار من ليلة واحدة).
قاعدة التثبيت عند الانحدار: عند رصد انحدار أو وضع طوارئ — تُجمَّد كل التعديلات،
             تُخفَّض التوقعات، ويُفتح دليل النجاة المناسب من الشاشة 09.
قاعدة الرفض: ضغط «غير موافق» يسجَّل ويمنع تكرار اقتراح التعديل نفسه في الأيام الثلاثة التالية.
قاعدة الشرح: كل تعديل يولَّد معه «لماذا» بجملة واحدة بلغة أم (لا تقرير) —
             بصيغة: [ماذا تغير] — [الملاحظة التي استند إليها] — [الاتجاه المرجو].
قاعدة التوقع الواقعي: أطول فترة نوم متصل هي المقياس المعروض (لا نسب مئوية ولا درجات).
```

## 4. وضع الطوارئ (من زر الشاشة 05)

بروتوكول من ثلاث خطوات: **تثبيت** كل توقيتات الخطة كما هي (لا تجديد جرعات التغيير أثناء الأزمة) → **إنزال** التوقعات لمعايير أسبوع سابق → **دعم**: رابط مباشر لدليل النجاة المناسب للعمر + نبرة تهدئة في كل النصوص (النبرة قرار تصميمي — راجع brand.md).

## 5. شاشة 07 — قواعد الاسترجاع والأمان

- المصادر المسموح استرجاعها فقط: الملف النامي + خطة اليوم + سجل التعديلات + مكتبة النوم. **لا بحث إنترنت مفتوح.**
- تعليمات النظام للنموذج (عند تفعيل مفتاح LLM): يجيب بلغة أم هادئة؛ يستشهد ببيانات الطفل الفعلية (العمر بالضبط، نمط الاستيقاظ، الخطة الحالية)؛ كل رد ينتهي بخطوة عملية لليلة؛ **لا تشخيص طبي إطلاقاً**.
- **الأعلام الحمراء الحرفية** (تُحوَّل لطبيب فوراً بعبارة مهذبة): حرارة، صعوبة تنفس، رفض الأكل المتكرر، خمول غير معتاد، بكاء ألم حاد مستمر، أي عمر أقل من 3 أشهر بمشاكل نوم مستمرة.
- الوضع القاعدي بلا مفتاح LLM: أجوبة مركّبة من قواعد المحرك والمكتبة بقوالب جاهزة — نفس الواجهة بالضبط، والمفتاح يُضاف لاحقاً من `.env` بلا تغيير في الشاشة.
- كل محادثة تُلخص في نهايتها إلى `chatSummaries` — الذاكرة تنمو من كل حوار.

## 6. الإشعارات (القرار الكامل)

- إشعار مسائي واحد فقط قبل الروتين بعشر دقائق، في وقت يحدده المستخدم.
- إن لم يُسجَّل الصباح: إشعار لطيف واحد بعد الظهر — **لا مطاردة ولا عدّاد انقطاع**.
- لا إشعار ليلياً إطلاقاً (الصمت الليلي).
